# EA1. Manipulación de Vectores en Java

## Descripción
Proyecto en Java desarrollado en Visual Studio Code con el JDK Eclipse Temurin para la manipulación y procesamiento de un vector de enteros.

## Funcionalidades
- Llenado del vector (15 posiciones) con validación de rango (10 a 100).
- Búsqueda de la posición de un valor ingresado por el usuario.
- Determinación del valor mayor y menor dentro del vector.
- Identificación de los múltiplos de un número X.
- Cálculo de la suma total de los elementos.
- Creación de un nuevo vector con los elementos por encima del promedio.
